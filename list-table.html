درس القوائم والجداول في HTML

في هذا الدرس سنتعلم كيفية إنشاء القوائم بأنواعها المختلفة، وإنشاء الجداول ودمج الخلايا.

أولاً: القوائم غير المرتبة

نستخدم العنصر <ul> لإنشاء قائمة غير مرتبة، والعنصر <li> لإنشاء كل عنصر داخل القائمة.

مثال عملي

  • HTML
  • CSS
  • JavaScript

ثانياً: القوائم المرتبة

نستخدم العنصر <ol> لإنشاء قائمة مرتبة بالأرقام، ويُستخدم العنصر <li> لكتابة عناصرها.

مثال عملي

  1. تعلم أساسيات HTML
  2. تعلم CSS
  3. تعلم JavaScript

ثالثاً: القوائم المتداخلة

القائمة المتداخلة هي قائمة توضع داخل عنصر من عناصر قائمة أخرى، وتساعدنا على تنظيم المعلومات في مستويات.

مثال عملي

  • تطوير الويب
    • HTML
    • CSS
    • JavaScript
  • الإحصاء

رابعاً: الجداول في HTML

نستخدم العناصر التالية لإنشاء جدول:

  • <table>: إنشاء الجدول.
  • <tr>: إنشاء صف.
  • <th>: إنشاء خلية عنوان.
  • <td>: إنشاء خلية بيانات.
  • <caption>: إضافة عنوان للجدول.

خامساً: دمج الخلايا

السؤال الأول

ما العنصر المستخدم لإنشاء قائمة غير مرتبة؟

الإجابة: <ul>

السؤال الثاني

ما العنصر المستخدم لإنشاء صف في الجدول؟

الإجابة: <tr>

السؤال الثالث

ما الفرق بين العنصرين th وtd؟

الإجابة: <th> يُستخدم لخلية العنوان، أما <td> فيُستخدم لخلية البيانات.
